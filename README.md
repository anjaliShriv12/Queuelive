# QueueLive

QueueLive is a modern virtual queue management concept designed to reduce physical waiting. Users can join a queue, track their position, view estimated wait times, and receive notifications when their turn is approaching.

This project was built as a frontend product experience for the Acdyon Technologies Frontend Challenge — Premium Home Page track.

## Demo Data

The queue information displayed in the interface is representative demo data created for the product preview. It does not represent real users, appointments, hospitals, or operational statistics.

No fabricated testimonials, customer logos, or user-count claims are used.

## Local Development

Clone the repository and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local Vite development URL.

## Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Design Approach

The design uses a dark interface with cyan accents to create a modern product-focused visual identity. The layout emphasizes clear hierarchy, restrained motion, responsive behavior, and product visualization rather than excessive marketing content.

## AI Usage

AI assistance was used during development for implementation guidance, component ideas, Tailwind CSS patterns, debugging, and code review.
